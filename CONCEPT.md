# 🗡️ THE TRAITORS — Concept v2 (locked specs + masala)

## 1. Core (tumhari specs — LOCKED)
- Naam: **The Traitors**
- **Sab apne-apne phone pe.** Ek banda room banata hai → 4-letter code / link / QR → baaki join. **Server hi host hai** — narration, roles, timers, murder, votes, hisaab sab server.
- 5–10 players. **2 Traitors** shuru mein, **+1 recruit** possible baad mein (max 3).
- **₹50 cap per head** → 10 log = ₹500 starting pot. ₹0 mode bhi.
- **Mission Stake: har mission se pehle har zinda banda ₹10 aur daalta hai** (10 log = ₹100 stake). Jeete = poora stake pot mein (+₹100). Haare = stake **Party Fund** mein. Kuch missions **Shield** ke liye.
  - Pot sirf badhta hai — kabhi minus nahi. Haare toh bas wo ₹10 party mein gaya.
  - Example: 10 log × ₹50 = ₹500 start → 4 missions × ₹100 = max ₹900 pot.
  - App har mission se pehle dikhata hai: *"Stake: ₹100 — jeete toh pot ₹600, haare toh pizza fund ₹100"* 🍕
- Missions aise ki **innocents pe shak jaaye**.
- 🌙 Raat: har Traitor ke phone pe **private Traitor chat** → decide: kisko murder / kisko recruit → server ko bolo → ho gaya.
- 🔴 Round Table: **3 min bahas + live group chat**, phir **vote — show jaisa**:
  1. Sab apne phone pe **chupke se** ek naam likhte hain (slate pe likhne jaisa, 30 sec).
  2. Sab lock ho gaye → server **ek-ek karke sabke saamne reveal** karta hai: *"Rohit ne vote diya... 🥁 ... PRIYA ko"* — 3 sec ka drum-roll har naam pe, phone vibrate.
  3. Screen pe live tally badhti hai jaise-jaise naam khulte hain. Poora table dekh raha hai kaun kisko pheka.
  4. Optional: reveal ke saath ek line bhi likh sakte ho (*"Kyunki tu chup tha jab Rohit mara"*) — show mein jaise bolte hain.
  - **Tie** → sirf tie wale do ke beech re-vote (tie wale vote nahi karte).
- Sabse zyada vote = Banished → "Card palto" → *"I was innocent"* / *"I was a Traitor"*.
- Banished ko **10 sec** — ek naam leke shak.

## 2. Mera masala 🌶️

### 2.1 Raat
- **Murder ya Poison Chai ☕** — poison: banda zinda, par agle round vote nahi kar sakta, usse pata nahi. Table ko sirf: "Aaj ek banda vote nahi kar payega."
- **Recruit = "Mano ya Maro"** — jisko offer aaya, 30 sec: haan = Traitor ban gaya (chat mein add), na = usi raat murder. Table ko kabhi pata nahi chalta kaun palta.
- **Bhoot Chat 👻** — mare hue log apni alag chat mein sab dekh sakte hain, bol nahi sakte. Poore game mein **ek baar** bhoot milke ek anonymous "Bhoot ka Ishaara" table pe bhej sakte hain — par mara hua Traitor bhi bhoot hai, toh ishaara galat bhi ho sakta hai 😈

### 2.2 Missions (60–90 sec, sabke phone pe saath-saath)
- **Wafadari ya Dhokha** — har banda secretly: Saath / Dhokha. Sab Saath = pot +₹100. Jisne Dhokha diya usko **Shield** milta hai, par app announce karta hai *"3 logon ne dhokha diya"* — naam nahi. Innocent bhi lalach mein dhokha dete hain → shak sab pe.
- **Sabse Sync** — ek sawaal, sab jawab. Jitne same, utne ₹. App **alag jawab wale ka naam** dikhata hai — chahe wo sach mein alag soch raha ho. Shak.
- **Kamzor Kadi** — sab secretly ek naam: "sabse kam trust". Jo top pe aaya, uske wajah se pot −₹50 — aur uska naam sabko dikhta hai. Innocent ka gussa asli.
- **Chup Reh 🤐** — 60 sec koi nahi hasega, app har phone pe alag-alag bewakoof lines bhejta hai (padhni hain zor se). Jo hasa = −₹30.
- **Ek Baar Ki Baat** — 30 sec mein ek sach jo kisi ko nahi pata, sab vote asli/bakwaas. Bakwaas nikla toh −₹.
- **Shield Race** — sabke phone pe ek 15-sec reflex game, top scorer ko Shield. (Traitor bhi jeet sakta hai — safe hone ka natak.)
- **Sabotage** — har mission mein **ek random banda** (Traitor ya innocent, koi bhi) ko secret "Sabotage" button dikhta hai. Daba diya = mission fail. Baad mein app: *"Kisi ne sabotage kiya tha."* Innocent bhi kar sakta hai bas mazaak mein — shak sab pe.
- (18+ toggle) **Never Have I Ever / Shot ya Sach** versions.

### 2.3 Round Table — Masala Cards (har round 1 random)
- **Seedha Sawaal** — ek banda kisi ko sawaal, 10 sec timer, jawab dena hi hai.
- **Gumnaam Chat 🕶️** — 60 sec ke liye group chat mein sab messages anonymous. Log wo bolte hain jo naam se nahi bolte.
- **Lie Detector 🤥 (fake)** — banda statement type karta hai, app "scan" karke random SACH/JHOOTH. Sabko pata hai fake hai, phir bhi chillam-chilli.
- **Ek Sach** — server ek asli hint deta hai: *"Ek Traitor ne pichhle round Rohit ko vote kiya tha."* Poora table hisaab lagane lagta hai.
- **Andha Vote** — aaj vote reveal NAHI honge, sirf result. (Ulta twist — kyunki normal vote to public hai.)
- **Double Banish** — aaj 2 jaayenge.
- **Chuppi** — ek random banda 3 min bol nahi sakta, sirf chat.

### 2.4 Random Events (server kabhi bhi)
- "Aaj raat do murder." / "Aaj mission double ₹." / "Ek banished wapas aayega (random)."
- **Blackmail** — ek innocent ko secretly: "Aaj X ko vote do, warna tum out." Kare toh innocent hoke bhi shak mein.

### 2.5 End Game
- 4 bache → har round sab vote: **"Khatam ya ek aur?"**
- Khatam → sab card palto. Ek bhi Traitor bacha = **poora pot Traitors ka**. Sab innocent = baraabar.
- 2+ Traitors bache → **Share ya Steal** (secret). Sab Share = baraabar. Ek Steal = sab uska. Sab Steal = **sab zero, poora pot Party Fund 🍕**.

### 2.6 Feel
- Dark, red/gold, candle-light. Har phone pe narration text (KJo mode 🎭) + vibrate + dark sound on murder.
- Sirf bada text + bade buttons — koi rule padhna nahi, server bolta jaata hai kya karna hai.
- Home screen pe install (PWA), no login, no ads.

### 2.7 Baad mein (Post-game)
- **Report**: kisne kisko vote kiya (poori timeline), "Sabse bhola", "Sabse bada Gaddaar", "Sabse bekaar clue", "Jhooth pakda gaya".
- **Hisaab**: Jeetne walon ka hissa + Party Fund — screenshot, WhatsApp.
- **History**: same group dubara khele toh stats jude — *"Aman: 4 baar Traitor, 4 baar bacha."*

## 3. Tech (short)
- Node + Socket.io server (real-time chat/votes), mobile-first web app, room codes.
- Sabke phone pe internet chahiye (WiFi/data). Ek banda room banata hai, code share.
- Yahan test ke liye live preview link milega. Asli night ke liye free hosting (Render/Railway) pe deploy — main steps dungi, 10 min ka kaam, ₹0.

## 4. Build order
- **v1**: Lobby → roles → Raat (Traitor chat + murder/poison/recruit) → 4 missions → Round Table (chat + masala card + vote) → Banish + 10 sec shak → End game (Share/Steal) → Hisaab screen.
- **v2**: Bhoot chat, Blackmail, random events, Report/History, 18+ pack, PWA install.
