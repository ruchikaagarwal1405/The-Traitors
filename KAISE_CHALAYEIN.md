# 🗡️ The Traitors — sabke phone pe kaise chalayein

## Option 1 (recommended): Render pe free host karo — ek baar, ~10 minute
Iske baad ek permanent link milega (jaise `https://the-traitors.onrender.com`) jo kabhi bhi, kahin se bhi khulega.

1. **GitHub account** banao (agar nahi hai) → github.com
2. GitHub pe **New repository** → naam `the-traitors` → Create.
3. `the-traitors.zip` unzip karo aur saari files repo mein upload kar do
   ("uploading an existing file" link → drag & drop → Commit). `node_modules` folder mat daalna (zip mein hai bhi nahi).
4. **render.com** pe jao → Sign up with GitHub → **New +** → **Web Service** → apna repo chuno.
5. Settings apne aap bhar jaayengi (render.yaml se): Build `npm install`, Start `npm start`, Plan **Free**. → **Deploy**.
6. 2–3 minute baad upar link dikhega: `https://the-traitors-xxxx.onrender.com` — **yahi link sabko bhejo.**

⚠️ Free plan 15 min khaali rehne pe so jaata hai — khelne se 1 minute pehle link khol lena (pehli baar 30–50 sec lagte hain).

## Option 2: Sab ek hi WiFi pe ho (laptop chahiye, internet nahi chahiye)
1. Laptop pe Node.js install karo (nodejs.org, LTS).
2. Zip unzip karo → us folder mein terminal kholo → `npm install` → `npm start`
3. Laptop ka IP nikalo (Windows: `ipconfig` → IPv4; Mac: System Settings → WiFi → Details).
4. Sab phone pe kholo: `http://192.168.x.x:3000` — laptop poore game ke dauran on rahe.

## Party ki raat — khelna kaise hai
1. Sab apne phone pe link kholo. **Add to Home Screen** kar lo (Chrome menu ⋮ / Safari share) — app jaisa full-screen khulega.
2. Ek banda naam likh ke **Create** → 4-letter code milega.
3. Lobby mein **Invite fellow players** → WhatsApp group mein link bhejo. Baaki log link kholte hi seedha join ho jaate hain (ya naam + code daal ke Join).
4. 5–10 players hone pe host ⚙️ mein stake set kare (₹0–₹50 per head, 🌶️ Masala optional) → **Start**.
5. Phone screen lock mat hone dena (auto-lock 5 min kar lo). Galti se band ho jaaye toh link dobara kholo — apni seat wapas mil jaati hai.
6. Paisa app mein nahi hai — end mein screen pe hisaab dikhta hai, UPI se aapas mein settle karo.

## Tips
- Sab ek hi kamre mein baithein — Circle of Shaq, tongue twisters, Chup Reh sab aamne-saamne mazedaar hain.
- Ek phone TV/laptop pe bhi khol sakte ho, sirf dekhne ke liye (join mat karna).
- Dobara khelne pe missions/puzzles automatically alag aayenge.
